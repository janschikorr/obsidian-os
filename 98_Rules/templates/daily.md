```yaml
id: daily-YYYY-MM-DD
type: daily
date: YYYY-MM-DD
weight:

protein:
fat:

steps:
cardio_min:

---

```

**Tracking-Properties** (alle optional, weglassen wenn kein Wert):
| Property | Einheit | Beispiel |
|---|---|---|
| `weight` | kg | `96.4` |
| `calories` | kcal | `1800` |
| `protein` | g | `150` |
| `fat` | g | `60` |
| `carbs` | g | `180` |
| `steps` | Schritte | `7500` |
| `cardio_min` | Minuten | `30` |
| `training_sets` | Sätze | `12` |
